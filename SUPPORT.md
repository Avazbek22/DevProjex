# Support

## Questions and usage help

Use [GitHub Discussions](https://github.com/Avazbek22/DevProjex/discussions)
for installation questions, usage help, workflow advice, and ideas that are not
yet actionable bug reports.

Before asking, check:

- [README.md](README.md);
- [Docs/CommandLine.md](Docs/CommandLine.md);
- [Docs/TerminalWorkspace.md](Docs/TerminalWorkspace.md);
- existing issues and discussions;
- `devprojex doctor --format json` for environment diagnostics.

## Bug reports

Use the repository issue forms for reproducible CLI or TUI defects. Remove
credentials, project contents, repository URLs, usernames, and other sensitive
data from logs and doctor output before posting.

Issues are not a guaranteed response-time support channel. Please provide a
minimal reproduction and remain available for follow-up questions.

## Security

Do not report vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).

## Unsupported requests

The maintainers cannot provide private project debugging, guarantee recovery
of data outside DevProjex's documented read-only/source and destination
contracts, or support unofficial binaries whose provenance cannot be verified.

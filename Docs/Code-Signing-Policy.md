# Code signing policy

Free code signing provided by [SignPath.io](https://about.signpath.io), certificate by [SignPath Foundation](https://signpath.org).

## What is signed

Windows executables in the portable release archives on GitHub Releases, from the first signed release onward. Microsoft Store packages are signed by Microsoft.

## How signed releases are built

Signed binaries are built from this public repository by GitHub Actions on GitHub-hosted runners. Every signing request is approved manually by an approver.

## Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. See the [privacy policy](../Packaging/Windows/StoreListing/privacy-policy.md) for the network features you can choose to use.

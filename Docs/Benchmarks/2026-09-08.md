# 2026-09-08: first hands-on comparison with Repomix

## Builds

| Product | Version |
|---|---|
| DevProjex | v5.2 development branch, before the MCP polish round (#306 to #308) |
| Repomix | Repomix in `--mcp` mode |

## Setup

- **Harness.** A Node bridge kept both stdio servers running and logged every call: duration,
  characters returned, and tokens estimated as characters divided by four.
- **Repositories.** Flask `d318b683` (236 files) and Repomix `85e3969b` (1,189 files).
- **Agent.** One agent per task, not told which server belonged to which product, limited to 14
  calls and without direct disk access.
- **Tasks.**
  - T1: where Flask stores sessions;
  - T2: how Repomix orders files;
  - T3: an overview of Flask;
  - T4: what `pack_codebase` includes.

## Results

| Task | DevProjex calls | Repomix calls | DevProjex tokens | Repomix tokens |
|---|---:|---:|---:|---:|
| T1 | 3 | 3 | 3,362 | 4,395 |
| T2 | 6 | 6 | 3,606 | 7,151 |
| T3 | 6 | 7 | 9,419 | 7,843 |
| T4 | 7 | 5 | 5,874 | 17,920 |
| **Total** | **22** | **21** | **22,261** | **37,309** |

All eight answers were correct. The agent said it trusted the DevProjex answer in all four
tasks, because every claim came with `path:line`.

## Defects found in DevProjex

| # | Defect | Effect |
|---|---|---|
| 1 | `search_project` with `context_lines` printed overlapping context again for each adjacent hit | In T1 lines 219 to 225 came back three times; about half the response was duplicate |
| 2 | The `pack_context` description did not list the accepted values of `detail`, `view`, `rank` and `focus` | The agent guessed `signatures` |
| 3 | `max_tokens` limited the content but not the report around it | About 600 tokens over the requested budget |
| 4 | `project` rejected the name returned by `list_projects` (`flask`) | The agent had to pass the full path |
| 5 | The first `related_files` call took 1.6 s cold against 38 ms warm; its footer used "supported" and "unsupported" without defining them | Slow first call, unclear output |
| 6 | `get_file` read one range of one file per call | One call per range |

## Weaknesses seen in Repomix

- Grep hits returned twice, as matches and as formatted output.
- Line numbers point into the packed file, not into the source file.
- No cap on grep results: one broad grep returned 174 hits, about 11,800 tokens.
- No tool to read a single file.

## Decisions

All six defects became 5.2 work: merged search windows, value lists in the descriptions, the
budget applied to the whole response, project names accepted, an explained and faster dependency
index, and batched `get_file` reads. The list was widened into issues #309 to #314.

## Caveats

- Tokens are characters divided by four, measured at the bridge, not what the model processed.
- The work was not equal on both sides: in T4 the agent pulled packed content into its context.
  The totals of 22,261 and 37,309 tokens did not hold in the paired run two days later (see
  [2026-09-10](2026-09-10.md)) and must not be quoted as a cost advantage.

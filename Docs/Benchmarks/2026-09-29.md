# 2026-09-29: release QA runs

Five runs on the last day before the 5.2 freeze. Each one found something the next one checked.

## Why

The 5.2 release QA had produced fixes to MCP notices and errors (#455, #456). Before the freeze
they had to be checked against Repomix on the task set of 13 September, and any complaint the
agents still had about the tools had to be either fixed or accepted.

## Incident before the first run

The first duel of the day ran on a stand that a `%TEMP%` cleanup had emptied: the httpx clone had
0 files left and a gutted `.git`, with the folders still in place. DevProjex honestly saw an empty
project, Repomix fetched httpx from GitHub through `pack_remote_repository`, and both sessions
"chose Repomix". The run was discarded. **Rule from this day:** before every series, check that each
repository has its expected file count and that `git log -1` works; re-clone the pinned tag if
not.

## Decisions

- **Kept:** #456 (honest notices, the empty-selection stage, the error code catalog), #457, and
  the "partial output" wording in `1ed69509`.
- **Weak spot carried into 5.2:** broad feature orientation (T3, J2).

## Lessons

- Check the scoring script before the result: two "misses" this day came from a regex that
  ignored bold paths and from one that required a directory in the path.
- A judge that does not see the code punishes precise claims it cannot check. Read its flags
  before counting them.

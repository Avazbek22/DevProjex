Correctness was stable across both readings; preference was not. Preference figures are quoted
only together with the share of order-dependent pairs.

Two conclusions from 11 September did not repeat. The token deficit became a small lead, and the
rule "Repomix is cheaper on broad exploration" split: broad T3 was cheaper for DevProjex, broad T6
for Repomix. The same task on the same server cost 45,824 and 23,299 tokens in two sessions (T1),
so per-task differences below a factor of two are noise.

**Harness defect found.** `run.mjs` skips a job when its `summary.json` already exists, and the arm
name `server_k` had already been used on 10 September for the filesystem server on a different
model. Four of the twelve DevProjex points would have been taken silently from another server.
**Rule:** a fresh arm name, or an empty `runs/` folder, for every series.

## 3. `1f4796ec` against `581e52f7`: declaration body in search

Four tasks (T1, T5, T7, N2), one session each per build, about $1.03.

| Metric | v5.2 `1f4796ec` | v5.2 `581e52f7` |
|---|---:|---:|
| Turns | 75 | 61 |
| Tool calls | 71 | 57 |
| Searches | 31 | 23 |
| Seconds | 277 | 228 |
| Cache read tokens | 1,976,495 | 1,727,942 |

| Tool response characters | 208,055 | 259,024 |
| Cost | $0.521 | $0.510 |
| Required paths missed | 2 of 18 | 5 of 18 |

The first real fall in calls, with worse coverage. The transcripts showed the cause: the body went
to the **first declaration in path order**, not to the best match. Five of fifteen bodies came
from test or benchmark files. In T7 the query `GetEffectiveLevel` received the body of
`LoggerAuditSinkConfiguration`, the first of 26 candidates, whose name does not contain the
searched term. The agent then stopped earlier, on the wrong code.

**Decision: fix, not roll back.** The body now goes first to a declaration whose printed name
contains the searched term, with the previous order as the tie-break. A rule that ranks tests
lower was rejected: it guesses by category, while a name match is a fact. The clean measurement
of the corrected body is on [2026-09-15](2026-09-15.md).

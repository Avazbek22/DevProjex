## 1) 它是什么以及为什么
DevProjex快速准备项目上下文：显示文件夹/文件结构，允许您选择带有复选框的项目，并将树和/或文件内容复制到剪贴板。对于代码审查、支持、学习以及与AI助手共享项目结构非常有用。

重要提示：DevProjex不会修改您打开的项目中的文件。

## 2) 项目树
* 文件/文件夹类型图标。
* 节点上的复选框。
* 展开/折叠。

复选框：选择一个节点适用于其子节点；父状态会自动重新计算。

热键：
* {mod}E — 全部展开
* {collapseAll} — 全部折叠（根保持展开状态）

### 上下文菜单
右键单击节点，或按聚焦节点上的{shift}F10或菜单键：
* 在文件资源管理器中显示/在Finder中显示/在文件管理器中打开 — 显示系统文件管理器中的项目；该标签与当前平台匹配。
* 复制完整路径 — 项目的绝对路径。
* 复制相对路径 - 从项目根目录开始的路径，以根文件夹名称开头，例如`project/src/File.cs`。
* 复制内容 - 对于文件：使用应用的内容转换复制内容，与复制和导出生成的内容完全相同。
* Select only this — 仅选中此节点并清除其余节点；仅当还检查了另一个项目时才显示。
* 展开分支/折叠分支 — 用于文件夹。

如果磁盘上不再存在该路径，则在文件管理器中打开该项目或复制其内容会显示错误消息；路径复制仍然有效。

## 3) 文件
* 打开文件夹... — 打开根文件夹 ( {mod}O)
* 新窗口 — 打开一个新的独立DevProjex实例
* 最近 — 最近打开的本地文件夹列表
* 刷新 — 重新扫描本地文件夹并重建树 (F5)
* 导出到文件：
  * 导出树
  * 导出内容
  * 导出树和内容
* 导出项目：
  * 到文件夹...
  * 至ZIP存档...

导出项目从当前树创建一个单独的文件夹或ZIP存档，同时保留目录结构。

尊重选定的文件类型、排除规则和选中的项目。如果未检查任何内容，则导出整个当前树。

复制文本和二进制文件，并保留包含的空文件夹。源文件没有被修改。结果无法保存在源项目中。

导出期间，您无法更改树或设置、使用过滤器、更改格式或预览模式、运行Git命令、刷新或打开其他项目。

格式规则：
* 导出树：
  * 仅限ASCII -> `.txt`。
  * JSON -> 默认`.json`，`.json`和`.txt`在“保存”对话框中均可用。
  * XML -> 默认`.xml`，`.xml`和`.txt`在“保存”对话框中均可用。
  * MD -> 默认`.md`，`.md`和`.txt`在“保存”对话框中均可用。
* 导出内容 — 始终为文本内容格式，`.txt`文件（树格式切换不适用）。
* 导出树和内容 — 始终为`.txt`文件；所选的树格式仅影响结果内的树块格式。

导出文件以UTF-8无BOM格式编写。

### 拖放
当没有加载项目时，拖放可以在启动区域（Drop Zone）中进行。

规则：
* 您可以删除一个文件夹；
* 您可以删除文件 - 在这种情况下，包含的文件夹将被打开；
* 如果删除了多个项目，则使用第一个合适的本地路径；
* 如果路径不可用或不存在，则应用与“打开文件夹...”中相同的访问检查；
* 不支持的或非本地的项目将被忽略。

### 最近的
“文件→最近”项显示最近打开的本地文件夹的历史记录。

规则：
* 仅本地文件夹被添加到列表中；
* 通过DevProjex克隆的Git存储库不会添加到此列表中；
* 不会创建重复项 - 再次打开同一文件夹会将其移至顶部；
* 最多可存储32个最近使用的文件夹；
* 应用程序启动之间的历史记录会被保留。

每个项目都显示父文件夹和项目名称，例如`Projects / App`。

## 4) 从终端启动
DevProjex提供交互式终端工作区以及脚本和CI的直接命令。

如果命令已设置，请打开终端并运行：
`devprojex --help`

这列出了顶级命令和选项。运行`devprojex help <command>`以查看该命令自己的选项和示例。

示例：
* `devprojex` — 打开交互式终端工作区。在工作区中，通过`:`命令行驱动操作（例如`:copy`、`:analyze`、`:branch`）；有关完整命令列表，请参阅内置工作区帮助和项目文档。
* `devprojex tui .` — 直接在终端工作区中打开指定的文件夹。
* `devprojex open . --preview` — 在桌面预览中打开当前文件夹。
* `devprojex analyze . --format json` — 将当前项目分析为JSON。
* `devprojex tree .` — 将项目树打印到终端。
* `devprojex export context. --format markdown -o ../devprojex-context.md` — 在源项目外部保存AI就绪上下文。
* `devprojex export project. --as folder -o ../devprojex-submission` — 将有效项目树导出到确切的文件夹。
* `devprojex export project. --as zip -o ../devprojex-submission.zip` — 将有效项目树导出到ZIP存档。
* `devprojex export context https://github.com/owner/repo -o -` — 打包远程存储库，无需自行克隆。
* `devprojex analyze . --git-mode tracked --exclude smart-ignore` — 使用Smart Ignore分析跟踪的Git文件。
* `devprojex mcp --root .` — 启动本地只读MCP服务器，以便AI代理可以安全地读取项目。

笔记：
* `.`表示当前终端文件夹；
* 带有空格的路径必须用引号引起来；
* `--git-mode`选择不进行Git过滤、`.gitignore`或跟踪的Git文件；
* `--exclude`与Git过滤分开控制普通排除；
* 分析和导出命令是确定性的，不打开桌面界面；
* `tui`、`open`、`analyze`和两个`export`命令也接受Git存储库URL；克隆进入托管缓存（`devprojex cache`）；
* 命令已记录别名和短标志 - 例如`export ctx`、`-f`、`-n`；`devprojex help`显示它们；
* `analyze --findings`列出脱敏结果但不显示原始值，`--fail-on-findings`会为CI返回非零退出代码；
* 该命令不会修改项目文件 - DevProjex在只读模式下工作。

如果`devprojex`命令不起作用，请在DevProjex中打开：
“帮助→从终端启动”。

## 5) Git
Git菜单仅适用于通过DevProjex (Git Clone) 克隆的项目。该应用程序不会触及您的文件 - 它仅适用于缓存。

缓存存储在用户的系统缓存目录中。运行`devprojex doctor`以查看解析的路径。

* 分支 — 显示可用分支的列表，并标记了活动分支；切换将树更新到选定的分支。如果本地已经存在分支，则切换为离线状态（不更新）。如果本地不存在，则获取并创建它。
* 获取更新 — 仅更新当前分支：获取并重置为origin/<branch>。对于Git Clone项目，F5执行相同的操作；常规的“文件→刷新”命令被禁用。

### 克隆窗口
在Git Clone窗口中，URL字段下方会出现“最近的存储库”列表。

规则：
* 仅当历史记录已包含最近克隆的存储库时，才会显示该列表；
* 仅存储库URL会添加到列表中；
* 本地文件夹不会添加到此列表中；
* 不会创建重复项 - 再次克隆同一存储库会将其移动到顶部；
* 最多存储16个最近的存储库；
* 应用程序启动之间的历史记录会被保留。

选择一个项目会自动填充URL字段。
克隆正在进行时，该列表会暂时隐藏。

## 6) 复制
### 树格式切换（ASCII / JSON / XML / MD）
该切换定义了操作的树表示格式，其中树是输出的一部分。

* ASCII — 有分支的文本树。
* JSON — JSON中的结构化树。
* XML — 用于解析器和工具的紧凑XML树。
* MD — 用于文档和AI提示的Markdown嵌套列表。

切换会影响：
* 复制树
* 复制树+内容
* 导出树
* 导出树和内容

切换不会影响：
* 复制内容
* 导出内容

### 复制树
复制项目树。
如果有选中的节点，则根据选择构建树；如果选择为空或无效，则复制整个树。
结果格式由树格式切换定义。
热键：{mod}{shift}C和{mod}{alt}C。

### 复制内容
复制文件内容：
* 如果检查文件——仅检查那些文件；否则——所有项目文件；
* 每个文件前面都有一个标头及其完整的本地路径（对于Git Clone项目 - 存储库Web路径）；
* 非文本文件被忽略（包括二进制文件）；
* 对于空文本文件，输出路径和行`[No Content, 0 bytes]`；
* 对于仅包含空格/换行符的文件，将输出路径和行`[Whitespace, N bytes]`。
热键：{mod}{alt}V.

### 复制树+内容
组合树和内容：
* 树是通过选择而构建的；如果选择为空/无效，则使用完整的树；
* 内容遵循与“复制内容”相同的规则；
* 树块格式由树格式切换定义。
热键：{mod}{shift}V。

### 树表示
树格式对同一选定项目树使用不同的表示形式。

JSON：
* `rootPath` — 用`/`规范化的绝对​​根路径。
* `tree` — 根文件夹的内容。
* JSON导出使用这种树格式：数组包含文件，对象包含子文件夹，`/`包含当前文件夹中的文件，`[]`代表空文件夹。

XML：
* 根节点是`<t r="...">`；
* 文件夹是`<d n="...">`；
* 文件是`<f>File.cs</f>`。

医学博士：
* 以`Root: ...`开头；
* 使用Markdown嵌套列表；
* 文件夹以`/`结尾。

树+内容：
* 所选的树格式适用于树块；
* 内容块仍然是文本；
* 内容块中的文件头使用带有`/`相对路径；
* 导出为`.txt`。

## 7) 预览模式
使用顶部栏中的眼睛图标按钮或使用{mod}B打开。

鼠标侧按钮遵循浏览器式导航：前进打开预览模式，后退关闭预览模式。重复当前方向没有效果。

{mod}{shift}F打开或关闭预览中文件内容的搜索。Enter或F3转到下一个匹配项；{shift}Enter或{shift}F3转到上一个匹配项。

在树旁边的单独工作区中显示最终结果。此模式不会复制到剪贴板，也不会单独导出到文件 - 它是一种查看模式。

默认情况下，工作区打开为：
* 左 — 项目树；
* center — 预览窗格；
* 右 — 设置面板（如果已打开）。

可用模式：
* 树
* 内容
* 树和内容

应用与复制和导出相同的规则：
* 已检查的节点受到尊重；
* 如果选择为空，则使用完整数据集；
* 应用当前忽略规则和选择选项。

此外：
* 预览中的文件由水平线分隔；
* 滚动时，当前文件的路径固定在顶部；单击固定路径会滚动回该文件的开头；
* 预览滚动条标记搜索匹配项和带有密文结果的行；单击标记跳至其所在行；按原样保留的结果保持标记，并且屏蔽路径标头在其第一行添加一个标记；
* 树和预览缩放可以独立存在。
* 在预览模式下，您可以复制完整的当前结果或当前可见文件块，而无需打开“复制”菜单。

按钮：
* 顶部预览岛左侧的复制按钮 — 复制当前预览模式：
  * 树
  * 内容
  * 树和内容
* 树窗格中的X — 隐藏树并仅保留预览窗格；
* 顶部预览窗格中的X — 完全关闭预览模式；
* 固定文件头中的小复制按钮 — 完全按照预览中显示的方式复制当前可见文件块；
* 再次按眼睛图标或{mod}B也会关闭预览模式。

当树窗格在预览中可见时，搜索和过滤可用。
如果树被隐藏，搜索和过滤将暂时不可用，直到您离开仅预览模式。

打开搜索栏，突出显示匹配项并允许导航。
* {mod}F — 显示/隐藏
* 输入 — 下一个结果
* {shift}输入 — 上一个
* Esc — 关闭

搜索仅自动扩展所需的分支；清除查询会折叠树（根除外）。

## 11) 选项（设置面板）
右侧可用：
* 应用设置
* 内容处理
* 排除情况
* 扩展

“排除”和“扩展”中的更改会在面板中进行，并在单击“应用设置”后应用。

复选框更改后，应用程序可能会在后台更新可用选项及其计数。仅在单击“应用设置”后才会重建生成的树。

如果使用状态栏中的X按钮取消可用选项更新，则不会应用未完成的更改，并且面板将返回到上次完成的状态。

关于“扩展”的注意事项：
* 此列表仅显示具有扩展名的文件；
* 没有扩展名的文件不会添加到此列表中，并由“排除”中的单独选项控制。

内容处理：
* 转换选定文本文件的内容而不更改树；
* “隐藏机密信息”和“隐藏个人数据”会替换检测到的值（第12.3和12.4节）；
* 压缩代码保留声明，同时缩短14种语言的命名实现；
* Strip comments删除跨20个语言包的注释和文档注释；
* 剥离空白行会删除同一包中仅包含空白的行，同时保留多行文字；
* 更改在“应用设置”后生效。

{mod}P — 显示/隐藏面板。

### 11.1 本地项目参数配置文件
对于本地文件夹，DevProjex会记住上次应用的项目参数：
* 选定的文件类型；
* 在“排除”部分中选择的选项。

单击“应用设置”时会执行保存。
当再次打开同一本地文件夹时，参数将自动恢复。

重要的：
* 仅保存本地项目的配置文件；
* 对于通过Git Clone打开的项目，不会保存配置文件；
* 如果某些保存的选项在当前项目中不再可用，则会跳过它们，并应用其余参数。
* 如果刷新或重新打开在“排除”中显示新的文件类型或选项，则默认情况下启用；
* 已经看到的选项保留用户的明确选择：禁用类型的新文件不会再次启用该类型。

## 12) 除外情况
“排除”部分控制从树、内容、复制和导出结果中排除哪些文件和文件夹。

仅当满足所有这些条件时才会显示项目：
* 如果文件有类型，则选择其文件类型；
* 没有启用的忽略规则将其排除。

忽略规则是累积的。如果至少一个启用的规则隐藏了某个项目，则另一规则无法使其可见。

### 12.1 可用规则
根据项目内容，可能会显示以下选项：

* Smart Ignore
* 使用.gitignore
* 仅跟踪Git文件
* 空文件夹
* 空文件
* 隐藏文件夹
* 隐藏文件
* 以点为前缀的文件夹
* 以点为前缀的文件
* 没有扩展名的文件

在Git存储库中，“使用.gitignore”和“仅跟踪的Git文件”作为稳定的复选框对保持可见。启用其中一个会清除另一个。再次单击活动复选框会将其清除，从而使两个Git过滤器保持关闭状态，而不更改Smart Ignore或基本排除。当其他选项的规则可以更改当前树时，会显示其他选项。因此，在切换另一个规则或文件类型后，该列表可能会发生变化。

新选项首次出现时默认启用。即使已知选项暂时从列表中消失，它也会保留用户的选择。

### 12.2 Smart Ignore
Smart Ignore隐藏依赖项、构建输出、缓存和其他项目服务工件。

DevProjex首先从其结构和标记文件中识别项目类型，例如：

* `.csproj`
* `package.json`
* `pyproject.toml`
* `Cargo.toml`

然后，在检测到的项目范围内应用相应堆栈的规则。例如，.NET规则不会扩展到相邻的Python或JavaScript项目。

仅有文件夹名称并不总是足够的。诸如`build`、`vendor`、`packages`、`cache`、`pkg`或`Library`之类的不明确名称也会通过其内容进行验证。这可以防止普通用户文件夹仅因为名称相似而被隐藏。

即使在明确检测到的项目之外，某些依赖项存储和服务目录也可以通过其特有的内部结构来识别。

项目范围发现是有限的，因此加载大型用户文件夹不会成为对每个目录的完全重复分析。常规结构使用浅层发现，而公认的单一存储库则进行更深入的搜索。找到范围后，Smart Ignore将应用于其整个子树，没有深度限制。

### 12.3 隐藏秘密
“隐藏秘密”默认处于关闭状态。它仅扫描选定的文本内容并替换每个检测到的值，保留文件及其周围的代码。当该选项关闭时，不会运行扫描，也不会显示计数。扫描当前选择后，标签显示检测到的值的个数；如果“保持原样”决策留下较少的隐藏值，则会显示检测到/隐藏，以及该行的?指标报告这两个计数。

遮蔽后的范围会在预览中突出显示。单击其中一个可仅将该处保留原样；使用{alt}↓ / {alt}↑在检测结果之间移动，按Enter切换当前结果。在终端工作区中，使用`[`和`]`在各处结果之间移动，并使用`Enter`或`Space`切换当前结果。此决定适用于当前会话中的预览、剪贴板、上下文导出、文件夹副本和ZIP，但不会保存到项目配置文件中。

预览上下文菜单提供更大范围的决定。右键单击检测结果，可通过一次操作将同一规则的所有结果或同一文件中的所有结果保留原样或再次隐藏。要手动标记文件内容中选定的值，请右键单击该值：“在此处隐藏…”只在当前会话中隐藏这一处，“始终隐藏…”为该值的每个出现位置创建持久标记，“隐藏…并标记为个人数据”则创建由“隐藏个人数据”控制的持久标记。“删除标记”会删除手动标记；如果检测器仍能匹配该值，它仍会保持隐藏。手动值必须是文件内容中选定的单行文本，长度为8到512个字符。创建标记会自动启用相应选项。持久标记只存储加密键控后的值标识和类别，绝不会存储原始文本。

文件夹或ZIP副本也会更改匹配的文本，并且可能不再构建或运行。二进制文件原封不动地复制且不会被扫描。选定的文本文件超过16 MiB或检测失败会停止操作，而不是导出未经检查的文本。

计数报告规则仅匹配。零并不意味着该项目是安全的。CLI使用`--hide-secrets`；技术详细信息和限制位于`Docs/HideSecrets.md`中。

### 12.4 隐藏个人数据
“隐藏个人数据”默认关闭。它会检测所选文本文件中的电子邮件地址、全局IP地址、路径中的本地用户名、MAC地址和国际电话号码。检测结果沿用“隐藏机密信息”的预览决定和输出管道；通过“隐藏……并标记为个人数据”创建的手动标记也属于此类并受该开关控制（第12.3节）。生成的路径标题和树根目录中的本地用户名会作为一个共享结果被遮蔽：计数器将其计为一个值，?指示器报告其隐藏或显示状态，单击一次即可切换所有被遮蔽的路径。

文档范围和主机、常见CI用户名、众所周知的公共DNS解析器以及记录的虚构电话范围保持可见。零匹配并不是隐私保证。CLI使用`--hide-private-data`；完整的规则和第一阶段的限制位于`Docs/HidePrivateData.md`中。

### 12.5 使用.gitignore
启用后，DevProjex将应用每个可访问的`.gitignore`，而不仅仅是打开文件夹根目录下的文件。

每个`.gitignore`都适用：

* 到包含它的文件夹；
* 其下方所有可访问的文件夹；
* 仅限于该范围内。

嵌套`.gitignore`中的规则不会影响父文件夹或同级文件夹。

对于特定路径，规则从父`.gitignore`到更深的文件进行处理。在一个文件中，规则是从上到下处理的。最后的匹配规则决定了Git结果。

以`!`开头的规则仅在其范围内取消早期的Git排除。当其父文件夹仍被排除时，它无法恢复文件。完全排除且无法访问的文件夹内的`.gitignore`不参与评估。

单独跳过格式错误或不受支持的行。该文件中的其他有效规则和相邻范围中的规则继续有效。

此选项仅涵盖常规工作树`.gitignore`文件。不应用`.git/info/exclude`中的规则和全局Git排除规则；有效的存储库路径比较设置，例如`core.ignoreCase`以及在macOS上的`core.precomposeUnicode`受到尊重。不遵循名为`.gitignore`的符号链接，这与Git的控制文件行为相匹配。如果无法读取常规`.gitignore`，则其目录范围将被排除在故障关闭之外，并且扫描会报告部分访问，而不是在没有完整规则评估的情况下静默包含文件。当路径所属存储库范围的可读索引可用时，跟踪的文件即使匹配`.gitignore`仍然可见；如果没有该索引或Git CLI，该范围将安全地退回到仅模式评估。

内置的`standard`配置文件选择`gitignore`加上`smart-ignore`、`hidden-folders` ”、`hidden-files` `dot-folders`、“dot-folders”、`dot-files`、`empty-folders`、`empty-files`和`extensionless-files`。

### 12.6 仅跟踪Git文件
“仅跟踪的Git文件”根据每个可读Git索引中记录的现有工作树文件构建树的Git阶段。修改后的跟踪文件和分阶段添加仍然包括在内；未跟踪的文件被排除。这是当前的工作树，而不是`HEAD`或远程存储库的历史快照。

每个可到达的嵌套存储库和工作树都在任何可到达的嵌套级别上独立解析。子存储库不会从其父存储库或同级存储库继承跟踪路径。此模式需要Git CLI；可读的空索引是有效的。如果终端工作区 ( TUI) 在此模式下启动并且无法加载适用的索引，则工作区不会打开。如果在打开的TUI工作区中以交互方式选择模式并且无法加载适用的索引，则更改将被拒绝，并且最后一个可用的Git模式保持活动状态。在相同情况下，直接命令返回策略或检查失败。DevProjex永远不会默默地退回到`.gitignore`。如果另一个适用的索引可读，则排除不可用的嵌套范围并显示警告。

在已打开的桌面工作区中，显式跟踪的选择保持可见并失败关闭：当准备失败时，输出和导出将被阻止，而部分准备继续并出现本地化警告。

启用后，“使用.gitignore”和“仅跟踪的Git文件”是互斥的。还可以清除活动复选框以禁用Git过滤。对于支持配置文件的本地项目，此状态与文件类型和其他排除设置一起保存。

### 12.7 Git过滤和Smart Ignore之间的关系
Git复选框和Smart Ignore是独立的控件。所选的Git模式首先应用于每个可到达的Git范围。然后，Smart Ignore处理剩余的项目，最后运行基本规则。

当所选的Git模式已经涵盖所有候选模式时，Smart Ignore可以保持隐藏状态，然后在更改或清除Git模式后出现。这两个Git复选框在Git存储库中仍然可用。

以`!`开头的Git否定规则仅取消Git结果。它不会禁用Smart Ignore或基本规则。

### 12.8 基本规则
“点前缀文件夹”和“点前缀文件”检查项目名称。

“隐藏文件夹”和“隐藏文件”检查系统隐藏属性。在某些平台上，点前缀名称和系统属性可能描述相同的项目或不同的项目。

“空文件”隐藏大小为0字节的文件。

“没有扩展名的文件”隐藏诸如`Dockerfile`、`Makefile`和`README`之类的文件。

“空文件夹”隐藏逻辑上空的文件夹。如果应用选定的文件类型和所有其他规则后不保留任何可见文件或子文件夹，则文件夹在逻辑上为空。

因此，在切换另一个规则后，空文件夹计数可能会发生变化：隐藏文件可以使其包含的文件夹在逻辑上为空。

### 12.9 计数器
规则旁边的计数显示其在当前设置下的直接贡献，而不是磁盘上类似项目的物理数量。

一项不会同时归属于多个重​​叠计数器。例如，`.git`文件夹可能同时具有点前缀名称和系统隐藏属性，但其排除仅归因于一个规则。

使用稳定顺序来选择排除项的所有者：

* 文件夹：`.gitignore`，Smart Ignore，点前缀名称，系统隐藏属性；
* 文件：`.gitignore`，Smart Ignore，点前缀名称，无扩展名，空文件，系统隐藏属性。

此命令仅影响计数器。最终可见性遵循一个更简单的规则：如果任何启用的机制将某个项目排除在外，则该项目将被隐藏。

### 12.1 0应用更改
切换复选框首先更新面板中的可用设置和计数器。选择“应用设置”后，将重建最终的树。

如果取消设置准备，DevProjex会将面板返回到上次完全完成的状态。不应用部分计算的规则。

## 13) 树和指标是如何计算的
结果取决于：
* 选定的扩展
* 忽略规则
* 有源滤波器
* 检查树节点（用于基于选择的操作）

如果访问被拒绝，节点将保留其常用名称和图标，并获得“[访问被拒绝]”后缀。

### 13.1 状态栏计数器显示什么
状态栏有两个块：
* Tree — 树文本输出的度量；
* 内容 — 导出文件内容输出的指标。

格式：
* 行数
* 字符
* ~词元（大约）

大值用紧凑后缀 (K/M) 显示。

重要的：
* “Tree”块中的“Lines”表示最终树表示中的行数，而不是磁盘上的文件数；
* 该值包括文件夹、文件和树服务元素（例如，拒绝访问的节点）。

### 13.2 指标如何计算
树指标：
* 根据同一导出管道生成的实际树输出计算；
* 尊重当前的树格式。

内容指标：
* 遵循与内容复制/导出相同的规则；
* 排除二进制文件；
* 空文件和仅空白文件通过服务标记进行计数（`[No Content, 0 bytes]`、`[Whitespace, N bytes]`）。

### 13.3 计数器何时更新
重新计算运行：
* 打开/刷新项目后；
* 应用设置（排除和扩展）后；
* 当树复选框发生变化时（带有去抖）；
* 切换树格式时（对于使用树输出的操作）。
* 当取消后台计算时，计数器将设置为0，直到下一次完成重新计算。

## 14) 图标
图标选择顺序：
1) 节点类型（文件夹/文件）
2) 确切名称（如果规则存在）
3) 扩大
4) 否则——未知

## 15) 主题和效果
主题部分允许您选择系统、浅色或深色以及一种背景效果：
* 透明度
* 模糊
* Mica

默认情况下选择系统并遵循操作系统主题更改。首次启动或重置设置后，浅色系统主题以常规不透明背景开始，而深色系统主题以模糊开始。如果无法确定系统首选项，DevProjex将使用Dark和Blur。浅色和深色独立地记住它们的效果。显式的浅色或深色选择会忽略系统更改，直到再次选择系统为止。

效果是相互排斥的。再次单击选定的效果可将其禁用并恢复常规的不透明背景。

可用设置：
* 背景透明度 — 可用于透明度和模糊。
* 顶部面板对比度 — 调整包含预览、搜索、过滤器和树格式命令的主面板。
* 菜单透明度 — 同样适用于主菜单及其子菜单。
* 边框可见性 — 调整界面边框的显示强度。

Mica使用平台的系统材质，没有单独的背景透明度设置。如果所选的模糊或Mica效果不可用，应用程序将首先尝试其他本机效果。仅当Blur和Mica都不可用时才使用常规不透明背景。

在透明模式下，主窗口背景保持透明。菜单、子菜单和其他弹出界面在支持时使用模糊，因此它们后面的树和内容元素不会影响可读性。

## 16) 帮助

### 16.1 更新
“帮助 → 更新”将当前版本与最新稳定的GitHub版本进行比较。自动检查默认关闭；启用后，DevProjex会在上次成功检查后至少7天后在启动时进行检查。该复选框立即生效。最新的成功结果会在应用程序运行之间保留，并且不会因以后的网络故障而被删除。安装仍然是用户操作。

### 16.2 重置设置
重置设置（帮助→重置设置）会恢复默认主题、效果、紧凑模式、动画设置和界面语言。项目配置文件、历史记录和磁盘上的文件不会更改。

### 16.3 重置数据
重置数据（帮助→重置数据）会删除保存的本地项目参数配置文件：
* 选定的文件类型；
* 在“排除”部分中选择的选项。

重要的：
* 本地文件夹的最近历史记录不会被清除；
* Git Clone窗口中最近的存储库历史记录未清除；
* 磁盘上的文件和文件夹不会被修改或删除。

## 17) 语言
通过语言菜单选择语言。
所选语言将在两次启动之间保存。“帮助→重置设置”清除保存的语言选择并将界面语言恢复为默认值。

## 18) 进度条和取消
状态栏的中心显示活动操作及其进度。

进度模式：
* 不确定 — 无百分比（操作持续时间未知）。
* 确定 — 带百分比 (0–100)。

行为：
* 后台数据计算时，显示百分比进度；
* 对于某些Git操作，当进度源提供百分比时，会显示百分比；
* 当操作花费明显时间时，会显示可用选项更新和设置应用程序；
* 快速操作完成但没有显示进度。

状态栏中的X按钮（取消）：
* 对支持取消的操作执行尽力取消；
* 停止后台数据计算；
* 当取消可用选项更新时，将面板返回到上次完成的状态；
* 对于不支持取消的操作，它会停止状态栏指示，而操作本身仍可能在后台完成。

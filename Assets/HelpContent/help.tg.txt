## 1) Ин чист ва барои чӣ
DevProjex контексти лоиҳаро зуд омода мекунад: сохтори ҷузвдонҳо/файлҳоро нишон медиҳад, имкон медиҳад элементҳоро бо қуттӣ интихоб кунед ва дарахт ё мундариҷаи файлҳоро ба буфер нусха бардоред. Барои code review, дастгирӣ, омӯзиш ва додани сохтори лоиҳа ба ёрдамчии AI қулай аст.

Муҳим: барнома танҳо дар режими хондан кор мекунад ва файлҳоро тағйир намедиҳад.

## 2) Дарахти лоиҳа
* Иконкаҳои навъи файл/ҷузвдон.
* Қуттиҳои интихоб дар гиреҳҳо.
* Кушодан/бастан.

Қуттиҳо: интихоб ба наслҳо татбиқ мешавад; ҳолати падар худкор ҳисоб мешавад.

Тугмаҳои зуд:
* Ctrl+E — кушодани ҳама
* Ctrl+W — бастани ҳама (реша кушода мемонад)

## 3) Файл
* Кушодани ҷузвдон… — кушодани ҷузвдони реша (Ctrl+O)
* Равзанаи нав — кушодани нусхаи нави мустақили DevProjex
* Охиринҳо — рӯйхати ҷузвдонҳои маҳаллии ба наздикӣ кушодашуда
* Навсозӣ — бозхондани ҷузвдони маҳаллӣ ва бозсозии дарахт (F5)
* Содирот ба файл:
  * Содироти дарахт
  * Содироти мундариҷа
  * Содироти дарахт ва мундариҷа

Қоидаҳои формат:
* Содироти дарахт:
  * ASCII -> танҳо `.txt`.
  * JSON -> пешфарз `.json`, дар равзанаи нигоҳдорӣ `.json` ва `.txt` дастрасанд.
  * XML -> пешфарз `.xml`, дар равзанаи нигоҳдорӣ `.xml` ва `.txt` дастрасанд.
  * MD -> пешфарз `.md`, дар равзанаи нигоҳдорӣ `.md` ва `.txt` дастрасанд.
* Содироти мундариҷа — ҳамеша формати матнии мундариҷа, файл `.txt` (тугмаи формати дарахт таъсир надорад).
* Содироти дарахт ва мундариҷа — ҳамеша файл `.txt`; формати интихобшудаи дарахт танҳо ба формати блоки дарахт дар натиҷа таъсир мерасонад.

Файлҳои содирот бо UTF-8 (бе BOM) навишта мешаванд.

### Drag & Drop
Drag & Drop дар майдони оғоз (Drop Zone) кор мекунад, вақте ки лоиҳа бор нашудааст.

Қоидаҳо:
* метавонед ҷузвдонро кашида партоед;
* метавонед файлро кашида партоед — дар ин ҳолат ҷузвдони он кушода мешавад;
* агар чанд объект партофта шавад, аввалин роҳи маҳаллии мувофиқ истифода мешавад;
* агар роҳ дастнорас бошад ё вуҷуд надошта бошад, ҳамон санҷиши дастрасӣ мисли «Кушодани ҷузвдон…» истифода мешавад;
* объектҳои дастгиринашаванда ё ғайримаҳаллӣ нодида гирифта мешаванд.

### Охиринҳо
Банди «Файл → Охиринҳо» таърихи ҷузвдонҳои маҳаллии ба наздикӣ кушодашударо нишон медиҳад.

Қоидаҳо:
* ба рӯйхат танҳо ҷузвдонҳои маҳаллӣ дохил мешаванд;
* репозиторийҳои Git, ки тавассути DevProjex клон шудаанд, ба ин рӯйхат дохил намешаванд;
* такрорҳо сохта намешаванд — кушодани дубораи ҳамон ҷузвдон онро ба болои рӯйхат мебарад;
* то 15 ҷузвдони охирин нигоҳ дошта мешавад;
* таърих байни оғози барнома нигоҳ дошта мешавад.

Барои ҳар банд номи ҷузвдони болоӣ ва номи лоиҳа нишон дода мешавад, масалан `Projects / App`.

## 4) Иҷро аз терминал
DevProjex-ро аз терминал иҷро кардан мумкин аст.

Агар команда аллакай танзим шуда бошад, терминалро кушоед ва иҷро кунед:
`devprojex --help`

Ҳамин тавр ҳамаи командаҳо, параметрҳо ва мисолҳои дастрасро мебинед.

Мисолҳо:
* `devprojex .` — папкаи ҷориро кушодан.
* `devprojex "C:\Projects\App"` — папкаи нишоншударо кушодан.
* `devprojex . --export tree` — дарахти лоиҳаро дар терминал баровардан.
* `devprojex . --export content` — мазмуни файлҳоро дар терминал баровардан.
* `devprojex . --export tree-content` — дарахт ва мазмунро дар терминал баровардан.
* `devprojex . --export tree-content -o context.txt` — натиҷаро ба файл нигоҳ доштан.
* `devprojex --benchmark "C:\Projects\App"` — workflow-и стандартии ҳисоботи лоиҳаро чен кардан.
* `devprojex --last --preview` — лоиҳаи охиринро бевосита дар режими preview кушодан.
* `devprojex --benchmark-ui "C:\Projects\App"` — сенарияи стандартии UI-ро чен кардан.
* `devprojex --session-metrics "C:\Projects\App"` — метрикаҳои сессияи UI-ро то пӯшидани равзана сабт кардан.

Хусусиятҳо:
* `.` папкаи ҷории терминалро маъно дорад;
* роҳҳое, ки фосила доранд, бояд дар нохунак бошанд;
* агар файли барориш нишон дода нашавад, натиҷа рост дар терминал чоп мешавад;
* команда файлҳои лоиҳаро тағйир намедиҳад — DevProjex дар реҷаи хондан кор мекунад.

Агар командаи `devprojex` кор накунад, дар DevProjex кушоед:
«Ёрӣ → Иҷро аз терминал».

## 5) Git
Менюи Git танҳо барои лоиҳаҳое дастрас аст, ки тавассути DevProjex клон шудаанд (Git Clone). Барнома ба файлҳои шумо даст намерасонад — танҳо бо кеш кор мекунад.

Кеш дар ҷузвдони муваққатии система нигоҳ дошта мешавад. Дар Windows одатан:
`%TEMP%\DevProjex\RepoCache`

* Шоха — рӯйхати шохаҳои дастрасро бо нишонаи шохаи фаъол нишон медиҳад; ҳангоми иваз кардан дарахт ба шохаи интихобшуда нав мешавад. Агар шоха аллакай маҳаллӣ бошад, ивазкунӣ бе шабака (бе навсозӣ) сурат мегирад. Агар шоха дар маҳаллӣ набошад, он тавассути fetch бор карда шуда, маҳаллӣ сохта мешавад.
* Гирифтани навсозиҳо — танҳо шохаи ҷориро нав мекунад: fetch ва reset ба origin/<шоха>. Барои лоиҳаи Git Clone тугмаи F5 ҳамин амалро иҷро мекунад; фармони одии «Файл → Навсозӣ» ғайрифаъол аст.

### Равзанаи клонкунӣ
Дар равзанаи Git Clone зери майдони URL метавонад рӯйхати «Репозиторийҳои охирин» нишон дода шавад.

Қоидаҳо:
* рӯйхат танҳо вақте пайдо мешавад, ки дар таърих аллакай репозиторийҳои ба наздикӣ клоншуда мавҷуд бошанд;
* ба рӯйхат танҳо URL-ҳои репозиторийҳо дохил мешаванд;
* ҷузвдонҳои маҳаллӣ ба ин рӯйхат дохил намешаванд;
* такрорҳо сохта намешаванд — клонкунии дубораи ҳамон репозиторий онро ба болои рӯйхат мебарад;
* то 7 репозиторийи охирин нигоҳ дошта мешавад;
* таърих байни оғози барнома нигоҳ дошта мешавад.

Агар шумо банде аз рӯйхатро интихоб кунед, URL ба майдони воридкунӣ худкор гузошта мешавад.
Ҳангоми клонкунии фаъол рӯйхат муваққатан пинҳон карда мешавад.

## 6) Нусха
### Тугмаи формати дарахт (ASCII / JSON / XML / MD)
Ин тугма формати намоиши дарахтро барои амалиётҳое муайян мекунад, ки дар натиҷа дарахт иштирок мекунад.

* ASCII — дарахти матнӣ бо шохаҳо.
* JSON — дарахти сохторӣ дар JSON.
* XML — дарахти XML-и кӯтоҳ барои parser-ҳо ва абзорҳо.
* MD — рӯйхати Markdown барои ҳуҷҷатгузорӣ ва AI prompt-ҳо.

Тугма ба инҳо таъсир мерасонад:
* Нусхаи дарахт
* Нусхаи дарахт + мундариҷа
* Содироти дарахт
* Содироти дарахт ва мундариҷа

Тугма ба инҳо таъсир намерасонад:
* Нусхаи мундариҷа
* Содироти мундариҷа

### Нусхаи дарахт
Дарахти лоиҳаро нусха мебардорад.
Агар гиреҳҳои интихобшуда бошанд, дарахт аз рӯйи интихоб сохта мешавад; агар интихоб холӣ ё номувофиқ бошад — дарахти пурра нусха мешавад.
Формати натиҷа бо тугмаи формати дарахт муайян мешавад.
Тугмаҳо: Ctrl+Shift+C ва Ctrl+Alt+C.

### Нусхаи мундариҷа
Мундариҷаи файлҳоро нусха мекунад:
* агар файлҳо интихоб шуда бошанд — танҳо онҳо; вагарна — ҳамаи файлҳои лоиҳа;
* файлҳои ғайриматнӣ нодида гирифта мешаванд (аз ҷумла бинарӣ);
* барои файлҳои матнии холӣ роҳ ва сатри `[No Content, 0 bytes]` бароварда мешавад;
* барои файлҳое, ки танҳо аз фосилаҳо/гузариши сатрҳо иборатанд, роҳ ва сатри `[Whitespace, N bytes]` бароварда мешавад.
Тугма: Ctrl+Alt+V.

### Нусхаи дарахт + мундариҷа
Дарахт ва мундариҷаро якҷо мекунад:
* дарахт аз интихоб; агар интихоб холӣ ё номувофиқ бошад — дарахти пурра;
* мундариҷа мувофиқи қоидаҳои «Нусхаи мундариҷа»;
* формати блоки дарахт бо тугмаи формати дарахт муайян мешавад.
Тугма: Ctrl+Shift+V.

### Намоишҳои дарахт
Форматҳои дарахт як дарахти интихобшудаи лоиҳаро ба шаклҳои гуногун нишон медиҳанд.

JSON:
* `rootPath` — роҳи мутлақи реша, ки бо `/` нормалӣ шудааст.
* `tree` — мундариҷаи ҷузвдони реша.
* Содироти JSON ин формати дарахтро истифода мебарад: массивҳо файлҳоро, объектҳо зерҷузвдонҳоро, `/` файлҳои ҷузвдони ҷориро дар бар мегирад, ва `[]` ҷузвдони холиро нишон медиҳад.

XML:
* гиреҳи реша — `<t r="...">`;
* ҷузвдонҳо — `<d n="...">`;
* файлҳо — `<f>File.cs</f>`.

MD:
* бо `Root: ...` оғоз мешавад;
* рӯйхати дохилии Markdown-ро истифода мебарад;
* ҷузвдонҳо бо `/` анҷом меёбанд.

Дарахт + мундариҷа:
* формати интихобшудаи дарахт ба блоки дарахт татбиқ мешавад;
* блоки мундариҷа матнӣ мемонад;
* сарлавҳаҳои файл дар блоки мундариҷа роҳҳои relative бо `/` истифода мекунанд;
* содирот дар `.txt` захира мешавад.

## 7) Реҷаи пешнамоиш
Бо тугмаи нишонаи чашм дар панели боло ё бо Ctrl+B кушода мешавад.

Натиҷаи ниҳоиро дар фазои кори ҷудогона дар канори дарахт нишон медиҳад. Ин реҷа худ аз худ чизеро ба буфер нусхабардорӣ намекунад ва ба файл содир намекунад — он танҳо барои дидан аст.

Бо нобаёнӣ фазои корӣ чунин кушода мешавад:
* дар чап — дарахти лоиҳа;
* дар марказ — ҷазираи пешнамоиш;
* дар рост — панели танзимот, агар он кушода буд.

Реҷаҳои дастрас:
* Дарахт
* Мундариҷа
* Дарахт ва мундариҷа

Ҳамон қоидаҳое татбиқ мешаванд, ки барои нусхабардорӣ ва содирот:
* гиреҳҳои интихобшуда ба ҳисоб гирифта мешаванд;
* агар интихоб холӣ бошад, маҷмӯи пурраи додаҳо истифода мешавад;
* қоидаҳои ҷории нодидагирӣ ва параметрҳои интихоб татбиқ мешаванд.

Илова бар ин:
* файлҳо дар пешнамоиш бо хатҳои уфуқӣ ҷудо мешаванд;
* ҳангоми гардондан роҳи файли ҷорӣ дар боло маҳкам мемонад;
* масштаби дарахт ва пешнамоиш метавонанд ҷудогона бошанд.
* дар реҷаи пешнамоиш метавонед ё натиҷаи пурраи ҷориро, ё блоки намоёни ҷории файлро бе ворид шудан ба менюи «Нусха» нусхабардорӣ кунед.

Тугмаҳо:
* тугмаи нусхабардорӣ дар қисми чапи ҷазираи болоии пешнамоиш — реҷаи ҷории пешнамоишро нусха мебардорад:
  * Дарахт
  * Мундариҷа
  * Дарахт ва мундариҷа
* X дар ҷазираи дарахт — дарахтро пинҳон мекунад ва танҳо ҷазираи пешнамоишро мемонад;
* X дар панели болоии пешнамоиш — реҷаи пешнамоишро пурра мебандад;
* тугмаи хурди нусхабардорӣ дар сарлавҳаи маҳками файл — блоки намоёни ҷории файлро маҳз ҳамон тавр нусха мебардорад, ки дар пешнамоиш нишон дода шудааст;
* пахши дубораи нишонаи чашм ё Ctrl+B низ реҷаи пешнамоишро мебандад.

Ҷустуҷӯ ва филтр то вақте дастрасанд, ки ҷазираи дарахт дар пешнамоиш намоён бошад.
Агар дарахт пинҳон шавад, ҷустуҷӯ ва филтр то баромадан аз реҷаи танҳо-пешнамоиш муваққатан дастнорас мешаванд.

## 8) Намоиш
### Масштаб
* Ctrl++ / Ctrl+= — калон кардан
* Ctrl+- — хурд кардан
* Ctrl+0 — баргардондан
* Ctrl + чархи муш — зуми нарм дар ҷазирае, ки курсор болои он аст

Рафтор:
* дар реҷаи оддӣ дарахт масштаб мешавад;
* дар пешнамоиш бо дарахти намоён, фармонҳои калон кардан, хурд кардан ва баргардондан аз меню ба дарахт ва пешнамоиш якбора татбиқ мешаванд;
* бо Ctrl + чархи муш дарахт ва пешнамоиш вобаста ба ҷойи курсор мустақилона масштаб мешаванд;
* дар реҷаи танҳо-пешнамоиш танҳо ҷазираи пешнамоиш масштаб мешавад.

Диапазон: 6–28, баргардондан — 15.

### Режими ихчам
Интерфейсро зичтар мекунад: фосилаҳо дар дарахт ва танзимот хурдтар мешаванд.
Ҳангоми фаъол будани фазои кори пешнамоиш режими ихчам худкор фаъол мешавад.

### Аниматсияи дарахт
Ҳангоми бурдани курсор ба сатрҳои дарахт аниматсияи ҳаракати нармро фаъол мекунад.

### Шрифти дарахт
Шрифти дарахт аз «Намоиш → Шрифти дарахт» интихоб мешавад.
«Пешфарз» шрифти стандартии дарахтро бармегардонад.
Шрифти интихобшуда баъд аз пахши «Истифодаи танзимот» дар панели танзимот татбиқ мешавад.

## 9) Ҷустуҷӯ дар дарахт
Панели ҷустуҷӯро мекушояд, мувофиқатҳоро равшан мекунад ва навигатсия медиҳад.
* Ctrl+F — нишон/пинҳон
* Enter — натиҷаи навбатӣ
* Shift+Enter — қаблӣ
* Esc — пӯшидан

Ҷустуҷӯ танҳо шохаҳои заруриро мекушояд; ҳангоми тозакунии дархост дарахт ҷамъ мешавад (ғайр аз реша).
Агар шумораи мувофиқатҳо хеле зиёд бошад, барнома метавонад кушодани худкор ва равшанкунии умумиро маҳдуд кунад, то интерфейс ҷавобгӯ бимонад.
Ҳангоми пӯшидани панели ҷустуҷӯ, дархост баъд аз анҷоми аниматсияи пӯшидан тоза мешавад.

Маҳдудиятҳо:
* ҳангоми кушодани ҷустуҷӯ, филтр худкор баста мешавад;
* ҷустуҷӯ дар пешнамоиш то вақте дастрас аст, ки ҷазираи дарахт намоён бошад;
* агар дарахт пинҳон шавад, ҷустуҷӯ муваққатан дастрас нест.

## 10) Филтр бо ном
Танҳо гиреҳҳои мувофиқ ва падарони онҳоро нишон медиҳад. Навсозӣ бо таъхир.
* Ctrl+Shift+N — филтрро нишон/пинҳон
* Esc — пӯшидани филтр

Маҳдудиятҳо:
* ҳангоми кушодани филтр, ҷустуҷӯ худкор баста мешавад;
* филтр дар пешнамоиш то вақте дастрас аст, ки ҷазираи дарахт намоён бошад;
* агар дарахт пинҳон шавад, филтр муваққатан дастрас нест.

## 11) Танзимот
Дар тарафи рост дастрас аст:
* Истифодаи танзимот
* Нодида гирифтан
* Навъҳои файл
* Ҷузвдонҳои сатҳи боло

Тағйирот дар «Нодида гирифтан», «Навъҳои файл» ва «Ҷузвдонҳои сатҳи боло» дар панел омода мешаванд ва баъд аз пахши «Истифодаи танзимот» татбиқ мегарданд.

Пас аз тағйири қуттии интихоб, барнома метавонад параметрҳои дастрас ва ҳисобкунакҳои онҳоро дар фон нав кунад. Дарахти ниҳоӣ танҳо баъд аз пахши «Истифодаи танзимот» бозсозӣ мешавад.

Агар навсозии параметрҳои дастрас бо тугмаи X дар сатри ҳолат бекор карда шавад, тағйироти нотамом татбиқ намешаванд ва панел ба ҳолати охирини анҷомёфта бармегардад.

Дар ҳар рӯйхат тугмаи Ҳама (ҳамаро фаъол/хомӯш) мавҷуд аст.

Эзоҳ дар бораи «Навъҳои файл»:
* дар ин рӯйхат танҳо файлҳои дорои васеъшавӣ нишон дода мешаванд;
* файлҳои бе васеъшавӣ ба ин рӯйхат дохил намешаванд ва тавассути банди алоҳида дар «Нодидагирӣ» идора мешаванд.

Ctrl+P — панелро нишон/пинҳон.

### 11.1 Профилҳои параметрҳои лоиҳаҳои маҳаллӣ
Барои ҷузвдонҳои маҳаллӣ, DevProjex параметрҳои охирини татбиқшудаи лоиҳаро нигоҳ медорад:
* ҷузвдонҳои сатҳи болоии интихобшуда;
* навъҳои файлҳои интихобшуда;
* қоидаҳои интихобшуда дар блоки «Нодидагирӣ».

Сабт ҳангоми пахши «Истифодаи танзимот» иҷро мешавад.
Ҳангоми боз кушодани ҳамон ҷузвдони маҳаллӣ параметрҳо худкор барқарор мешаванд.

Муҳим:
* профилҳо танҳо барои лоиҳаҳои маҳаллӣ сабт мешаванд;
* барои лоиҳаҳое, ки тавассути Git Clone кушода шудаанд, профилҳо сабт намешаванд;
* агар қисми бандҳои сабтшуда дар лоиҳаи ҷорӣ дигар дастрас набошанд, онҳо гузаронида мешаванд ва параметрҳои боқимонда татбиқ мегарданд.
* агар баъд аз навсозӣ ё бозкушоӣ ҷузвдони нави сатҳи боло, навъи нави файл ё банди нав дар «Нодидагирӣ» пайдо шавад, он бо нобаёнӣ фаъол мешавад;
* бандҳои аллакай маълум интихоби равшани корбарро нигоҳ медоранд: файлҳои нави навъи хомӯшшуда он навъро дубора фаъол намекунанд.

## 12) Нодидагирӣ
Рӯйхати «Нодидагирӣ» аз рӯи роҳи ҷорӣ ва ҷузвдонҳои сатҳи болоии интихобшуда ба таври худкор сохта мешавад.

Тартиби пунктҳо:
* Smart ignore (агар татбиқшаванда бошад)
* Истифодаи .gitignore (агар татбиқшаванда бошад)
* Ҷузвдонҳои холӣ
* Файлҳои холӣ
* Ҷузвдонҳои пинҳон
* Файлҳои пинҳон
* Ҷузвдонҳо бо нуқта дар оғоз
* Файлҳо бо нуқта дар оғоз
* Файлҳои бе васеъшавӣ

Рӯйхат аз дарахти ҷорӣ ва қоидаҳои фаъол вобаста аст. Банди асосӣ танҳо вақте нишон дода мешавад, ки натиҷаро тағйир дода тавонад. Агар унсурҳои мувофиқ аллакай бо қоидаи дигар пинҳон шуда бошанд, банд метавонад муваққатан нопадид шавад ва баъд аз тағйири танзимот боз пайдо гардад.

Бандҳои `.gitignore` ва Smart Ignore низ таъсири воқеии худро ба дарахт ба назар мегиранд. Банди равшан хомӯшшуда метавонад намоён монад, то онро дубора фаъол кардан мумкин бошад.

Банди нав ҳангоми бори аввал пайдо шудан бо нобаёнӣ фаъол мешавад. Банди аллакай маълум интихоби равшани корбарро нигоҳ медорад, ҳатто агар муваққатан аз рӯйхат нопадид шуда бошад.

Хатти зери «Истифодаи .gitignore» қоидаҳои Git/Smart-ро аз қоидаҳои асосии намоиш ҷудо мекунад.

### 12.1 Минтақаи татбиқи қоидаҳо
Барнома минтақаҳои лоиҳа (scope)-ро месозад, ки қоидаҳои нодидагирӣ дар онҳо татбиқ мешаванд:
* реша (агар дар реша `.gitignore` ё нишонаи лоиҳа бошад)
* ҷузвдонҳои сатҳи аввал
* зерҷузвдонҳои дохилии лоиҳа

Ҷустуҷӯи минтақаҳои дохилии лоиҳа маҳдуд аст ва аз сохтори ҷузвдон вобаста мебошад.
Барои лоиҳаҳои оддӣ ҷустуҷӯи сатҳӣ истифода мешавад. Дар monorepo-ҳои шинохташуда ҷустуҷӯ метавонад амиқтар иҷро шавад.
Ҷузвдонҳои хизматӣ, вобастагиҳо ва артефактҳои тасдиқшудаи build ҳангоми ҷустуҷӯи минтақаҳо гузаронида мешаванд.

Ин маҳдудият танҳо ба ёфтани минтақаҳои дохилӣ барои `.gitignore` ва Smart Ignore дахл дорад. Вақте минтақа ёфт шуд, қоидаҳо ба мундариҷаи он тавассути скани одии дарахт татбиқ мешаванд.

### 12.2 «Истифодаи .gitignore»
* Фаъол: қоидаҳои `.gitignore` дар минтақаҳои ёфтшуда татбиқ мешаванд.
* Ғайрифаъол: қоидаҳои `.gitignore` пурра хомӯш мешаванд.

Дар ҷузвдони бисёрлоиҳаӣ, `.gitignore`-и як лоиҳа ба лоиҳаҳои ҳамсоя берун аз минтақаи худ татбиқ намешавад.

### 12.3 Smart Ignore-и гибридӣ
Smart Ignore артефактҳои маъмулии build, кэшҳои абзорҳо ва анборҳои вобастагиҳоро пинҳон мекунад. Он ду усули якдигарро пуркунанда истифода мебарад:

1. Қоидаҳои лоиҳа. Файлҳои нишона ба мисли `.csproj`, `package.json`, `pyproject.toml` ё `Cargo.toml` навъи лоиҳаро муайян мекунанд. Сипас қоидаҳои технологияи мувофиқ дар минтақаи он татбиқ мешаванд.
2. Санҷиши артефактҳо. Барои номҳои духӯра ба мисли `build`, `vendor`, `packages`, `cache`, `pkg` ё `Library` танҳо ном кофӣ нест. Мундариҷаи ҷузвдон бояд тасдиқ кунад, ки он натиҷаи build, кэш ё анбори вобастагиҳо мебошад.

Дар лоиҳаи шинохташуда ҷузвдони стандартии артефакт аз рӯи якҷоягии навъи лоиҳа ва номи ҷузвдон муайян мешавад. Берун аз ин шароит Smart Ignore эҳтиёткорона амал мекунад ва ҷузвдони одиро танҳо аз сабаби номи монанд пинҳон намекунад.

Баъзе артефактҳои умумии тасдиқшуда метавонанд берун аз минтақаи лоиҳа низ пинҳон шаванд. Ин имкон медиҳад ҷузвдонҳои кории омехта бе паҳн кардани қоидаҳои як лоиҳа ба ҷузвдонҳои сарчашмаи ҳамсоя коркард шаванд.

Ҳангоми хомӯш кардани Smart Ignore ҳар ду усул хомӯш мешаванд.

### 12.4 Қоидаҳои асосӣ
Пунктҳо:
* Ҷузвдонҳои пинҳон
* Файлҳои пинҳон
* Ҷузвдонҳо бо нуқта дар оғоз
* Файлҳо бо нуқта дар оғоз
* Ҷузвдонҳои холӣ
* Файлҳои холӣ
* Файлҳои бе васеъшавӣ

Ҳангоми фаъол будан, пункт унсурҳои мувофиқро аз дарахт ва аз натиҷаҳои нусха/содирот пинҳон мекунад.
Қоидаҳои асосӣ ҷудо аз `.gitignore` ва Smart Ignore фаъол мешаванд, аммо натиҷаи ниҳоӣ ҳамеша аз рӯи дарахти ҷорӣ баъд аз татбиқи ҳамаи филтрҳои фаъол ҳисоб мешавад.

### 12.5 Ҳамкории `.gitignore` ва Smart Ignore
1. Як лоиҳа бо як минтақа ва `.gitignore`.
Одатан танҳо «Истифодаи .gitignore» нишон дода мешавад. Ин тугма сиёсати умумии нодидагирии лоиҳаро идора мекунад: ҳангоми фаъол будан `.gitignore` ва Smart-қоидаҳои татбиқшаванда якҷоя кор мекунанд, ҳангоми ғайрифаъол будан ҳар ду механизм хомӯш мешаванд.

2. Як лоиҳа бе `.gitignore`.
Smart Ignore нишон дода мешавад, агар ба дарахт таъсир расонида тавонад.

3. Ҷузвдони корӣ бо чанд лоиҳа.
`.gitignore` танҳо дар минтақаҳое татбиқ мешавад, ки дар онҳо ёфт шудааст. Smart Ignore метавонад алоҳида нишон дода шуда, қоидаҳоро дар дигар минтақаҳои татбиқшаванда пурра кунад. Дар ин ҳолат тугмаҳо мустақилона кор мекунанд.

4. Ҷузвдон бе қоидаҳои татбиқшаванда.
Агар `.gitignore` ва Smart Ignore ба натиҷа таъсир нарасонанд, ин бандҳо нишон дода намешаванд. Танҳо қоидаҳои асосии татбиқшаванда мемонанд.

### 12.6 Ҷузвдонҳои холӣ
Ҷузвдонҳои холии мантиқиро аз дарахт ва аз натиҷаҳои нусха/содирот пинҳон мекунад.
Ҷузвдони холии мантиқӣ — ҷузвдонест, ки баъд аз татбиқи қоидаҳои ҷории намоиш, `.gitignore`, Smart Ignore ва навъҳои интихобшудаи файл дигар ягон фарзанди намоён надорад.
Агар худи ҷузвдон бо қоидаҳои дигар пинҳон нашуда бошад, маҳз ҳамин пункт хориҷ кардани онро аз дарахт идора мекунад.

### 12.7 Файлҳои холӣ
Файлҳои холии ҳаҷмашон 0 байтро аз дарахт ва аз натиҷаҳои нусха/содирот пинҳон мекунад.

### 12.8 Файлҳои бе васеъшавӣ
Файлҳои бе васеъшавиро (масалан: `Dockerfile`, `Makefile`, `README`) аз дарахт ва аз натиҷаҳои нусха/содирот пинҳон мекунад.

### 12.9 Ҳисобкунакҳо дар блоки «Нодидагирӣ»
Назди қоидаҳои асосии дастрас шумора дар формати `(N)` нишон дода мешавад.

Ҳисобкунак саҳми бевоситаи ҳамин қоидаро дар маҷмӯи ҷории танзимот нишон медиҳад, на шумораи умумии унсурҳои монандро дар диск. Аз ин сабаб тағйири як банд метавонад ҳисобкунаки банди дигарро тағйир диҳад: як унсур набояд ҳамзамон ҳамчун натиҷаи чанд қоидаи ҳампӯш ҳисоб шавад.

Масалан, дар Windows ҷузвдони `.git` метавонад ҳам бо нуқта оғоз шавад ва ҳам пинҳон бошад. То вақте ки «Ҷузвдонҳо бо нуқта дар оғоз» онро пинҳон мекунад, он ҳамчун натиҷаи «Ҷузвдонҳои пинҳон» алоҳида ҳисоб намешавад.

## 13) Дарахт ва метрикаҳо чӣ тавр ҳисоб мешаванд
Натиҷа вобаста аст ба:
* интихобшуда ҷузвдонҳои сатҳи боло
* интихобшуда навъҳои файл
* қоидаҳои нодида гирифтан
* филтр фаъол
* гиреҳҳои бо checkbox интихобшуда дар дарахт (барои амалиётҳои вобаста ба интихоб)

Агар дастрасӣ набошад, гиреҳ бо Дастрасӣ нест нишон дода мешавад.

### 13.1 Ҳисобкунакҳои сатри ҳолат чиро нишон медиҳанд
Дар сатри ҳолат ду блок ҳаст:
* Дарахт — метрикаҳои барориши матнии дарахт;
* Мундариҷа — метрикаҳои барориши мундариҷаи файлҳо.

Формат:
* Сатрҳо
* Аломатҳо
* ~Токенҳо (тахминӣ)

Қиматҳои калон дар формати кӯтоҳ (K/M) нишон дода мешаванд.

Муҳим:
* «Сатрҳо» дар блоки «Дарахт» — шумораи сатрҳои намоиши ниҳоии дарахт аст, на шумораи файлҳо дар диск;
* ба ин арзиш ҷузвдонҳо, файлҳо ва унсурҳои хизматии дарахт (масалан, гиреҳҳои дастнорас) дохил мешаванд.

### 13.2 Метрикаҳо чӣ тавр ҳисоб мешаванд
Метрикаҳои дарахт:
* аз матни воқеии дарахт ҳисоб мешаванд, ки аз ҳамон pipeline-и содирот сохта мешавад;
* формати ҷории дарахтро ба назар мегиранд.

Метрикаҳои мундариҷа:
* бо ҳамон қоидаҳои нусха/содироти мундариҷа ҳисоб мешаванд;
* файлҳои бинарӣ дохил намешаванд;
* файлҳои холӣ ва танҳо фосиладор бо маркерҳои хизматӣ ҳисоб мешаванд (`[No Content, 0 bytes]`, `[Whitespace, N bytes]`).

### 13.3 Ҳисобкунакҳо кай нав мешаванд
Бозҳисобкунӣ иҷро мешавад:
* пас аз кушодан/навсозии лоиҳа;
* пас аз татбиқи танзимот (ignore, навъҳои файл, ҷузвдонҳои реша);
* ҳангоми тағйири checkbox дар дарахт (бо debounce);
* ҳангоми иваз кардани формати дарахт (барои амалиётҳое, ки дарахтро истифода мебаранд).
* агар ҳисобкунии фонӣ бекор шавад, ҳисобкунакҳо то бозҳисобкунии пурраи навбатӣ ба 0 гузошта мешаванд.

## 14) Иконкаҳо
Тартиби интихоб:
1) навъи гиреҳ (ҷузвдон/файл)
2) номи дақиқ (агар қоида бошад)
3) васеъшавӣ
4) дар акси ҳол — номаълум

## 15) Мавзӯъ ва эффектҳо
Дар бахши «Мавзӯъ» мавзӯи равшан ё торик ва як эффекти заминаро интихоб кардан мумкин аст:
* Шаффофият
* Тирагӣ
* Mica

Эффектҳо ҳамзамон истифода намешаванд. Пахши дубораи эффекти интихобшуда онро хомӯш карда, заминаи одии ношаффофро бармегардонад.

Параметрҳои дастрас:
* Шаффофияти замина — барои Шаффофият ва Тирагӣ дастрас аст.
* Контрасти панели боло — панели асосиро бо фармонҳои preview, ҷустуҷӯ, филтр ва формати дарахт танзим мекунад.
* Шаффофияти меню — ба менюи асосӣ ва зерменюҳои он яксон татбиқ мешавад.
* Намоёнии сарҳадҳо — равшании сарҳадҳои интерфейсро танзим мекунад.

Mica маводи системавии платформаро истифода мебарад ва параметри алоҳидаи шаффофияти замина надорад. Агар система эффектро дастгирӣ накунад, барнома намуди бехатари ношаффофро истифода мебарад.

## 16) Ёрӣ

### 16.1 Барқарор кардани танзимот
Барқарор кардани танзимот (Ёрӣ → Барқарор кардани танзимот) мавзӯъ, эффектҳо, режими ихчам, аниматсияи дарахт ва забони интерфейсро ба қиматҳои пешфарз бармегардонад. Профилҳои лоиҳа, таърих ва файлҳои диск тағйир дода намешаванд.

### 16.2 Барқарор кардани маълумот
Барқарор кардани маълумот (Ёрӣ → Барқарор кардани маълумот) профилҳои сабтшудаи параметрҳои лоиҳаҳои маҳаллиро нест мекунад:
* ҷузвдонҳои сатҳи болоии интихобшуда;
* навъҳои файлҳои интихобшуда;
* қоидаҳои интихобшуда дар блоки «Нодидагирӣ».

Муҳим:
* таърихи «Охиринҳо» барои ҷузвдонҳои маҳаллӣ тоза карда намешавад;
* таърихи «Репозиторийҳои охирин» дар равзанаи Git Clone тоза карда намешавад;
* файлҳо ва ҷузвдонҳои лоиҳаҳо дар диск тағйир дода намешаванд ва нест карда намешаванд.

## 17) Забонҳо
Забон аз менюи Забон интихоб мешавад.
Забони интихобшуда байни оғозҳои барнома нигоҳ дошта мешавад. «Ёрӣ → Барқарор кардани танзимот» интихоби забони захирашударо пок мекунад ва забони интерфейсро ба пешфарз бармегардонад.

## 18) Progress-бар ва бекоркунӣ
Дар қисми марказии сатри ҳолат амалиёти фаъол ва прогресс нишон дода мешавад.

Режимҳои прогресс:
* Indeterminate — бидуни фоиз (давомнокӣ номаълум аст).
* Determinate — бо фоиз (0–100).

Рафтор:
* ҳангоми ҳисобкунии фонӣ фоизи прогресс нишон дода мешавад;
* барои қисми амалиётҳои Git фоиз танҳо вақте нишон дода мешавад, ки манбаи прогресс онро диҳад;
* навсозии параметрҳои дастрас ва татбиқи танзимот вақте нишон дода мешаванд, ки амалиёт вақти назаррас гирад;
* амалиётҳои зуд бе нишон додани прогресс анҷом меёбанд.

Тугмаи X (бекоркунӣ) дар сатри ҳолат:
* барои амалиётҳое, ки бекоркуниро дастгирӣ мекунанд, best-effort бекоркунӣ иҷро мекунад;
* ҳисобкунии фонии маълумотро бозмедорад;
* ҳангоми бекор кардани навсозии параметрҳои дастрас панелро ба ҳолати охирини анҷомёфта бармегардонад;
* барои амалиётҳои бе дастгирии бекоркунӣ индикацияро дар сатри ҳолат мебандад, вале худи амалиёт метавонад дар фон анҷом ёбад.

## 19) Эзоҳҳо
* Бо нобаёнӣ мавзӯи торик бо эффекти Тирагӣ истифода мешавад. Агар система эффектро дастгирӣ накунад, барнома намуди бехатари ношаффофро истифода мебарад.
* Ҳангоми нокифоя будани иҷозат, барнома метавонад бозоғозӣ бо ҳуқуқи баланд пешниҳод кунад; агар рад шавад — огоҳӣ нишон дода мешавад.

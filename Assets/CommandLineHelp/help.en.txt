DevProjex

Usage:
  DevProjex --path <folder> [options]
  DevProjex.exe --path <folder> [options]
  devprojex --path <folder> [options]
  devprojex.exe --path <folder> [options]
  DevProjex <folder> [options]

Value syntax:
  --path <folder> and --path=<folder> are both supported.

Options:
  --path <folder>                 Open a project folder.
  --lang <code>                   UI language: en, ru, es, pt, pt-pt, de, fr, it, tg, uz, kk.
  --report [file]                 Write a JSON analysis report.
                                  Use --report - to write JSON to stdout.
  --report-path <file>            Write a JSON analysis report to a specific file.
  --report-format json            Report format. JSON is the v1 format.
  --benchmark <folder>            Run the standard project report benchmark.
  --benchmark-ui <folder>         Run the standard desktop UI benchmark.
  --benchmark-output <file>       Write the detailed benchmark JSON to a specific file.
  --session-metrics <folder>      Open the desktop app and record UI session metrics until exit.
  --session-metrics-output <file> Write the detailed session metrics JSON to a specific file.
  --export <mode>                 Export project text: tree, content, tree-content.
                                  Defaults to stdout when --output is omitted.
  --output, -o <file|->           Write export text to a file or stdout with -.
  --export-format, --format ascii|json|xml|md
                                  Tree format for tree and tree-content exports.
  --last                          Open the most recent local project folder.
  --preview                       Open the desktop preview after loading the project.
  --preview-mode tree|content|tree-content
                                  Select the preview content mode at startup.
  --tree-format ascii|json|xml|md Select the desktop tree format at startup.
  --tree-filter <text>            Open the tree filter with this query.
  --preview-search <text>         Open preview and the tree search bar with this query.
  --include-root, --roots <name>  Include one root folder. Can be repeated.
  --include-extension, --ext <ext>
                                  Include one extension. Can be repeated.
  --ignore <name|none>            Use exact ignore options for automation. Can be repeated.
  --strict                        Return a failure exit code when the report has diagnostics.
  --no-ui, --silent               Run analysis without showing the window.
                                  Writes a JSON report to stdout when no report or export is specified.
  --version                       Print application version.
  --help, -h, /?                  Show help.

Ignore option names:
  smart-ignore, git-ignore, hidden-folders, hidden-files,
  dot-folders, dot-files, empty-folders, empty-files,
  extensionless-files, none

Examples:
  DevProjex "C:\Projects\App"
  DevProjex.exe --path "C:\Projects\App"
  devprojex --last --preview
  devprojex "/home/me/projects/app" --preview-mode tree-content --tree-format md
  devprojex "/home/me/projects/app" --tree-filter Services
  devprojex.exe --path "C:\Projects\App" --report
  devprojex "/home/me/projects/app"
  DevProjex "/home/me/projects/app"
  DevProjex --path "C:\Projects\App" --report
  DevProjex --path "/home/me/projects/app" --no-ui
  devprojex --no-ui --path "/home/me/projects/app" --report -
  devprojex --path "/home/me/projects/app" --export tree -o -
  devprojex --path "/home/me/projects/app" --export tree-content -o context.txt
  devprojex --no-ui --path "/home/me/projects/app" --report --strict
  DevProjex --path "C:\Projects\App" --no-ui --report-path "C:\Reports\app.json"
  DevProjex --path "C:\Projects\App" --roots src --ext cs --ignore none --report
  devprojex --benchmark "C:\Projects\App"
  devprojex --benchmark-ui "C:\Projects\App"
  devprojex --benchmark "/home/me/projects/app" --benchmark-output result.json
  devprojex --session-metrics "C:\Projects\App" --preview --tree-format md
  devprojex --session-metrics "/home/me/projects/app" --session-metrics-output session.json

Notes:
  Windows Store command devprojex.exe starts the packaged DevProjex UI app.
  Windows portable builds can enable the devprojex command from Help -> Launch from terminal.
  --no-ui is a mode of the same app, not a separate CLI binary.
  Use Help -> Launch from terminal in the UI to inspect platform-specific command setup.
